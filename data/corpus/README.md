# Scam / benign message corpus (fine-tune & LLM eval)

Standalone normalized JSONL for training and evaluation. **Not** merged with, symlinked to, or derived from `hk50`, `data_v2`, friend hard-negative sets, or the formal 366-row WhatsApp eval corpus used in this repo.

## Layout

| Path | Purpose |
|------|---------|
| `raw/` | Download cache (gitignored). Safe to delete; re-run ingest to refill. |
| `normalized/*.jsonl` | Commit-safe, one record per line (schema below). |
| `ingest_stats.json` | Last run counts (regenerated by ingest). |

## Record schema

Each line is one JSON object.

**Required**

| Field | Description |
|-------|-------------|
| `id` | Stable id: SHA-256 prefix of `source\|key` (see ingest script). |
| `text` | Message body; light email/phone redaction applied on ingest (`XXX`). |
| `label` | `scam` \| `benign` \| `unknown` |
| `source` | `uci_sms` \| `paulkm` \| `vanila434` \| `other` |
| `source_url` | Canonical dataset URL |
| `license` | SPDX-style tag, e.g. `cc_by_4`, `apache_2`, `research_uci` |
| `collected_at` | ISO date (collection or ingest, per source) |
| `lang` | `yue` \| `zh-Hant` \| `zh-Hans` \| `en` \| `mixed` \| `unknown` |

**Optional** (when present): `scam_type`, `channel`, `has_url`, `urls`, `split` (`train` \| `dev` \| `holdout_public`), `notes`, `provenance` (`real` \| `hand_authored` \| `synthetic`).

### Split policy

- **UCI SMS**: deterministic 10% `dev`, remainder `train` (hash of `id`; not tied to any in-repo eval set).
- **vanila434**: Hugging Face `train` → `train`; official `holdout` → `holdout_public` (never included in `combined_train.jsonl`).
- **combined_train.jsonl** / **combined_dev.jsonl**: union of all sources with matching split only.

## Rebuild

```bash
# Optional: only for ingest (not required for npm test / bot runtime)
pip install datasets huggingface_hub

# Gated paulkm (after Hub access approval):
# export HF_TOKEN=...

python3 scripts/ingest_corpus.py
```

Writes `normalized/*.jsonl`, refreshes `ingest_stats.json`, and caches downloads under `raw/`.
